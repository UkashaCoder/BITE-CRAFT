# 🚀 BITE CRAFT

### One Platform. Five Creative Tools. Unlimited Possibilities.

BITE CRAFT is an all-in-one creative software platform designed to bring multiple powerful creative applications together in one place.

## 🎨 Included Software

- **UI CRAFT** – UI/UX design and code export.
- **IMAGE CRAFT** – Image editing and AI image tools.
- **VIDEO CRAFT** – Video editing and effects.
- **LOGO CRAFT** – Logo and brand design.
- **4K CRAFT** – Image enhancement and upscaling.

## ✨ Main Features

- Unified software launcher
- Modern dashboard
- Project management
- Export tools
- Plugin support
- Responsive interface
- Independent software modules

## 🛠️ Technologies

HTML, CSS, JavaScript, React, Node.js and SQLite.
